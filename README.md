# FinancialLedger

A simple Android app for managing personal finances – track income and expenses, view category breakdowns, and see visual pie‑chart summaries. Built with Kotlin, AndroidX, Room for local storage, and MPAndroidChart for graphics.

## Features
- Add income & expense entries
- Categorize transactions
- Persistent storage via Room
- Pie‑chart summary of income vs. expense
- Dark‑theme toggle

## Build
The project uses Gradle 8.5. CI is set up with GitHub Actions (`.github/workflows/android.yml`).
